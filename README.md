# Blackjack

A simple command-line Blackjack game made in Python using Object-Oriented Programming concepts.

## Features
- 52-card deck
- Random card shuffling
- Betting system with chips
- Dealer AI
- Hit or Stand options
- Ace value adjustment
- Replay system

## Technologies
- Python 3
- Random module

## How to Run

1. Download or clone the project
2. Open terminal in the project folder
3. Run:
python blackjack.py
